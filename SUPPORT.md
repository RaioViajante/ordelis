# Support

Ordelis is in **early development** and maintained on a best-effort basis. There are no releases, installers or downloads yet, the desktop app is an interface preview over sample data, and **no response or fix time is guaranteed**.

## Documentation and setup help

Start with the [documentation index](docs/README.md). For building the project and running its checks, see the [development guide](docs/development/README.md) and the [desktop commands](desktop/README.md#commands). The [README](README.md) says what exists today and what is only planned.

## Using GitHub issues

Issues are for actionable reports about this repository. Search the [existing issues](https://github.com/RaioViajante/ordelis/issues) first.

- **A bug or a documentation error:** open a [bug report](https://github.com/RaioViajante/ordelis/issues/new?template=bug_report.yml). Say what you did, what you expected and what happened. Documentation that is wrong, unclear or missing counts as a bug.
- **An idea or a missing capability:** open a [feature request](https://github.com/RaioViajante/ordelis/issues/new?template=feature_request.yml). Check [features](docs/product/features.md) and the [roadmap](docs/product/roadmap.md) first; the capability may already be planned.
- **A general question:** there is no separate question channel. If the documentation does not answer it and you think it should, open a bug report about the documentation.

Do not paste credentials, tokens, raw agent transcripts, provider output or personal file paths into an issue.

## Security vulnerabilities

Do not report a vulnerability in a public issue. Follow [SECURITY.md](SECURITY.md) to report it privately.

## Other projects

- The command-line runtime was inherited from [MCO](https://github.com/mco-org/mco). A problem that exists only in upstream MCO may be better reported there. If you are unsure, report it here.
- Problems in third-party agent CLIs or model providers should be reported to those vendors.
